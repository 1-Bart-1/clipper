stop looping the active clip (it loops by default)

fullscreen
n / enter
name box / save
ctrl + z
undo a mark, a nudge or an added clip
0
reset the picture zoom

Scroll on the picture to zoom it and drag to pan; scroll on the bar to zoom the timeline instead. Click a marker to select it, then nudge it with the arrows. Cuts are stream-copied, so a clip can start up to one keyframe (~2 s) before the in point. Originals are never touched.
